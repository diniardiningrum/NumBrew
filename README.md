# NumBrew

NumBrew adalah permainan simulasi kafe edukatif. Kelola kafe kecil, siapkan minuman, layani pelanggan, dan pelajari pengaruh biaya bahan, harga jual, diskon, serta biaya operasional terhadap keuntungan.

## Fitur

- Membeli bahan dan mengelola persediaan kafe.
- Menghitung harga pokok penjualan (HPP) dan menentukan harga menu.
- Menjalankan promosi serta melayani pelanggan dengan preferensi dan anggaran yang berbeda.
- Meninjau laporan penjualan dan keuntungan setelah setiap hari.
- Menyimpan progres permainan secara lokal di browser.

## Persyaratan

- Node.js
- npm

## Memulai

Pasang dependensi:

```bash
npm install
```

Jalankan server pengembangan:

```bash
npm run dev
```

Buka URL lokal yang ditampilkan di terminal untuk mulai bermain.

## Perintah yang tersedia

| Perintah | Keterangan |
| --- | --- |
| `npm run dev` | Menjalankan server pengembangan Vite. |
| `npm run build` | Memeriksa tipe dan membuat hasil build produksi di `dist/`. |
| `npm run preview` | Meninjau build produksi secara lokal. |
| `npm test` | Menjalankan seluruh pengujian satu kali. |
| `npm run test:watch` | Menjalankan pengujian dalam mode watch. |
| `npm run typecheck` | Memeriksa tipe TypeScript. |
| `npm run format` | Memformat file sumber. |
| `npm run format:check` | Memeriksa format tanpa mengubah file. |
